# ADR-0001: 系统架构决策

## 状态

已采纳（2026-05-18）

## 背景

lp 进销存从零设计架构，需在技术选型、部署模式、数据隔离、业务策略等方面做出顶层决策。

## 决策记录

### 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | Vue3 | 用户现有技术积累 |
| 后端 | Node.js | 与前端语言统一，生态丰富 |
| 数据库 | MySQL | 用户已有环境，进销存场景完全胜任 |
| 交互 | JSON API | 业务逻辑在后端，前端只做展示 |

### 部署与租户

| 决策 | 选择 | 理由 |
|---|---|---|
| 部署模式 | SaaS 多租户 | 目标用户无运维能力 |
| 数据库隔离 | 每商户独立数据库 | 数据隐私，独立备份恢复 |
| 注册流程 | 手机号自助注册，自动建库，引导选模板 | 无需人工介入，可规模化 |

### 前端策略

- 页面以写死组件为主，不做拖拽编辑器
- 用户在实体上增减字段时，页面自动联动反映
- 预置进销存模板（商品、供应商、客户、采购单、销售单、库存）

### 业务策略

| 决策 | 选择 | 理由 |
|---|---|---|
| 成本核算 | 移动加权平均 | 简单实时，用户好理解 |
| 角色权限 | 管理员 / 操作员 / 只读 | 覆盖进销存小商户 99% 场景 |
| 权限颗粒度 | 菜单级 | 不做按钮级，保持简单 |
| 多仓库 | 支持，出入库指定仓库 | 中国进销存场景几乎必遇 |
| 打印 | 一期 A4 浏览器打印 | 无需对接硬件 |
| 导出 | 全部报表支持 Excel | 高频需求 |

### 商业化

- 免费版：全部功能，月订单量上限 500 单
- 专业版：无限制 + Excel 高级报表 + API 开放

## 影响

- 需要实现租户域名路由和动态数据库连接
- 需要实现自动建库和模板数据初始化
- 商品/供应商/客户等实体需支持自定义字段
- 库存计算引擎需实现移动加权平均算法
